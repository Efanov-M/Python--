# Python-разработчик — расширенный курс

Учебное портфолио по программе «Python-разработчик: расширенный курс» на платформе
«Нетология». Здесь собраны мои домашние задания и курсовой проект: Python-скрипты,
SQL-запросы, веб-приложения, тесты, схемы баз данных и скриншоты выполнения работ.

**Автор:** Ефанов Михаил Евгеньевич.

## Направления подготовки

- **ООП и работа с API:** наследование, полиморфизм, специальные методы, HTTP-запросы и обработка ошибок.
- **Работа с данными:** чтение и запись текстовых файлов, обработка JSON и CSV, регулярные выражения.
- **Возможности Python:** итераторы, генераторы и декораторы.
- **Базы данных:** проектирование связей, создание таблиц PostgreSQL, выборки, JOIN и агрегатные функции.
- **Веб-разработка:** REST API на FastAPI и aiohttp, Django REST framework, фильтрация, валидация и права доступа.
- **Тестирование:** pytest, тестовый API-клиент, фикстуры, model_bakery и подмена внешних API-вызовов.
- **Сбор данных:** получение страниц через requests и разбор HTML с BeautifulSoup.

## Курсовой проект

[CLI-утилита для Яндекс.Диска и cataas.com](course-project/README.md) объединяет
темы ООП, API, декораторов и обработки исключений. Утилита позволяет получать
информацию о диске, просматривать файлы, создавать папки, загружать локальные файлы
и изображения котов по URL. Вызовы API записываются в CSV-журнал.

Точка входа — [main.py](course-project/main.py). Зависимости перечислены в
[requirements.txt](course-project/requirements.txt), примеры тестов клиента
Яндекс.Диска находятся в [tests/tests/test_yadisk.py](course-project/tests/tests/test_yadisk.py).

стиль `snake_case`, используемый в импортах. Скриншоты и схемы находятся в папках
`assets` и `screenshots` рядом с соответствующими работами.

## Как работать с репозиторием

Выберите работу в таблице выше и откройте её README или исходный файл.
Репозиторий состоит из отдельных учебных проектов: общего окружения и единой
команды запуска для всех заданий нет.

Запускайте скрипты из папки соответствующего задания: часть примеров обращается
к файлам данных по относительным путям. Если у проекта есть `requirements.txt`
или `requirements-dev.txt`, устанавливайте зависимости в отдельное виртуальное
окружение. Порядок подготовки базы данных и запуска Django-приложений описан
в их README; конфигурация контейнера FastAPI находится рядом с его исходным кодом.

Материалы отражают учебные решения. API объявлений на FastAPI и aiohttp хранят
данные в памяти процесса, поэтому при перезапуске приложения записи теряются.
